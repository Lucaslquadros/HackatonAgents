# Agente de Panorama e Priorização

Agente da plataforma Hack_OS (ver `../ROADMAP.md`, item 6) que leva o squad
de um tema amplo — ou de uma lista de categorias dadas pelo edital — até
2 ou 3 problemas candidatos ranqueados, prontos para o Agente de Visão
Sistêmica (`../agente-sistemico/`) aprofundar em CLD.

Segue o fluxo AI-DLC solo descrito em `CLAUDE.md`. Comece por
`01-inception/INCEPTION.md`.
